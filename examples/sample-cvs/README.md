# Fictional Sample CVs

These examples are deliberately fictional demonstrations of the canonical `cvs.content` structure. The people, contact details, employers, metrics, and credentials are illustrative only; they must not be represented as real candidates or real work histories.

| File | Target user | Template and market orientation |
|---|---|---|
| `amina-juma-finance.json` | Mid-career compliance and finance candidate | `ats_classic`, EAC/UK-oriented, English |
| `baraka-mponzi-software.json` | Software engineer pursuing remote-global roles | `ats_modern`, US/remote-oriented, English |
| `neema-selemani-hospitality.json` | Hospitality operations candidate applying locally | `visual_local`, Tanzania/EAC-oriented, English, fictional profile portrait |

Each fixture is exercised by the deterministic ATS lint test suite. They use reverse-chronological experience, no national ID, plain-text contact links, standard CV sections, and quantified action-verb bullets.
