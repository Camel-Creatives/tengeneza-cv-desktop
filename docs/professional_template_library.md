# Professional CV Template Library Expansion

The new templates are deliberately different **document systems**, rather than color reskins. Every design preserves a linear text reading order, screen-reader-friendly semantic headings, ATS-safe content extraction, and controlled spacing. The sample portraits are clearly fictional and exist only to make the profile-capable preview documents realistic.

## Quality gate

Each source fixture must show a portrait, quantified outcomes, standard ATS headings, no sensitive national-ID content, readable contact information, and a single-page output unless the professional content genuinely requires more. Each template must demonstrate a visibly different composition, not merely a changed heading colour.
